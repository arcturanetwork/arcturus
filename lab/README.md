# Arcturus Operator Training Infrastructure

The training substrate behind Arctura Network's elite agentic AI operator. Six complementary certification tracks, one shared capstone, and a project-first curriculum that builds real systems — not exam dumps.

## Certification Stack

1. NVIDIA Certified Professional: Agentic AI (NCP-AAI) — primary track
2. AWS Certified Solutions Architect – Professional (SAP-C03 target)
3. Certified Kubernetes Administrator (CKA)
4. NVIDIA Certified Professional: Generative AI LLMs (NCP-GENL)
5. ISC2 Certified Cloud Security Professional (CCSP)
6. Google Cloud Professional Machine Learning Engineer (PMLE)

**Thesis:** Architect, deploy, secure, evaluate, and operate trustworthy agentic systems. Every objective maps to original labs and verifiable evidence.

## Structure

```
lab/
  courses/         objective maps, lessons, labs, and track gates
  studies/         per-track study guides, scenario banks, rubrics
  projects/        the Arcturus reference implementation (shared capstone)
  capstone/        working agent code — orchestration, memory, knowledge, eval
  assessments/     readiness rubric, evidence audit, scenario exam engine
  evidence/        captured runtime proof from lab execution
  resources/       versioned primary sources and supplemental media
  tests/           repository-wide test suite
```
