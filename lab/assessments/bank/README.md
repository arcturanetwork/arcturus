# Original scenario bank

These questions were written for this course from public objectives. They are not recalled certification items. Four questions per track provide a first retrieval-practice diagnostic, not exam-readiness evidence.

Use each question closed-book. For every miss, write why each distractor fails, link the governing objective, perform or design a remediation lab, then retest after at least 48 hours. A small bank is easy to memorize, so repeated high scores on this file do not satisfy the readiness gate.
